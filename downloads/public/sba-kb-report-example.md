# 첫 응답 2시간으로 — 고객 문의 응대 개선 계획
루미엘 고객지원팀 · 팀장 보고 · 2026년 11월

## 한 줄 요약
배송 문의 자동 답변과 응대 순서 재정리로, 첫 응답 시간을 6시간 → 2시간으로 줄이고 재문의율을 18% → 10%로 낮춤

## 1. 추진 배경
- 문의가 3개월 새 21% 증가 (7월 3,800 → 9월 4,600건)
- 같은 기간 상담원은 5명 그대로 → 응답 지연 · 불만 증가

## 2. 현황 · 문제점
| 항목 | 현재 | 문제 |
|---|---|---|
| 첫 응답 시간 | 평균 6시간 | 경쟁사 평균 [확인 필요] |
| 재문의율 | 18% | 첫 답변이 불충분 |
| 문의 유형 | 배송 42% · 교환/환불 31% · 사용법 27% | 단순 반복 문의가 절반 가까이 |

## 3. 개선 방안 (3가지)
1. **배송 문의 자동 답변** — 자주 묻는 10개를 챗봇 답변으로 전환 → 배송 문의 절반 자동 처리 목표
2. **응대 순서 재정리** — 교환 · 환불을 우선 배정, 단순 문의는 자동 답변으로
3. **답변 표준 문구집** — 유형별 답변 30개를 만들어 상담원 작성 시간 단축

## 4. 추진 일정
| 단계 | 기간 | 담당 |
|---|---|---|
| 1. 자동 답변 10개 구축 | 12월 | 고객지원팀 |
| 2. 응대 순서 변경 · 문구집 | 1월 | 고객지원팀 · 물류팀 |
| 3. 효과 점검 · 보완 | 2월 | 팀장 |

## 5. 기대 효과
- 정량 : 첫 응답 6시간 → 2시간, 재문의율 18% → 10%
- 정성 : 상담원이 복잡한 문의에 집중, 고객 불만 감소

## 확인 필요 항목
- 경쟁사 평균 응답 시간 · 챗봇 도입 비용
