# 딥리서치 검증 체크리스트

## 조사 시작 전

- [ ] 조사 목적과 최종 사용처를 한 문장으로 적었다.
- [ ] 핵심 질문을 3~6개로 나눴다.
- [ ] 지역, 기간, 대상, 제외 범위를 정했다.
- [ ] 정부기관·공식 문서 등 우선 출처를 지정했다.

## 결과 확인

- [ ] 사실과 AI의 추정을 구분했다.
- [ ] 중요한 수치의 원 조사기관과 조사 시점을 확인했다.
- [ ] 표본 수와 조사 방법을 확인했다.
- [ ] 링크를 직접 눌러 실제 페이지가 존재하는지 확인했다.
- [ ] 서로 다른 출처 두 곳 이상에서 핵심 내용을 교차 확인했다.
- [ ] 확인되지 않은 항목은 ‘확인 불가’로 표시했다.

## AI에 추가로 요청할 문장

```text
출처를 기관명과 조사 시점까지 표시해줘.
확실한 사실과 추정을 구분해줘.
각 링크가 어떤 주장을 뒷받침하는지 함께 적어줘.
수치가 있다면 원 조사기관, 표본 수, 조사 방법을 알려줘.
확인할 수 없는 내용은 추측하지 말고 ‘확인 불가’라고 표시해줘.
```
