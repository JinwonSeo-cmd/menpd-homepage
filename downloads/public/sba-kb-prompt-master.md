# 프롬프트 대가 (KB) — PE7 좋은 예시 모음

## 쓰는 법
- 대필 봇은 이 파일의 예시 수준(구체성 · 문체)을 따라 쓴다
- 예시는 형식만 참고하고, 내용은 사용자의 요청으로 바꾼다
- 모르는 정보는 지어내지 말고 [채워주세요]

## 좋은 프롬프트의 5가지 습관
1. 역할은 경력 · 분야까지 한 줄로 (예 : 15년 경력 홍보 디자이너)
2. 대상은 ‘나’와 ‘읽는 사람’을 둘 다 적는다
3. 절차는 “먼저 ~ 하고, 내가 고르면 ~” 처럼 멈춤 지점을 넣는다
4. 자료는 “아래 정보만 써” 로 울타리를 친다
5. 형식은 비율 · 분량 · 파일 종류까지 숫자로

## 예시 ① 포스터
[PE1 역할] 너는 15년 경력의 홍보 디자이너야.
[PE2 대상] 나는 화장품 회사 마케팅 담당자고, 보는 사람은 20~30대 직장인이야.
[PE3 목표] 신제품 수분크림 출시 포스터를 만들려고 해.
[PE4 절차] 먼저 콘셉트 3가지를 한 줄씩 제안하고, 내가 고르면 만들어줘.
[PE5 샘플] 첨부한 포스터의 분위기를 참고해. 그대로 베끼지는 마.
[PE6 자료] 제품명 : 아쿠아 데이 크림 / 가격 : 29,000원 / 출시 : 11월 20일 — 이 정보만 써.
[PE7 형식] 글씨 없는 4:5 세로 이미지 1장.

## 예시 ② 보고서
[PE1 역할] 너는 기업 기획 보고서를 20년 써 온 기획 전문가야.
[PE2 대상] 나는 고객지원팀 담당자고, 읽는 사람은 팀장이야.
[PE3 목표] 문의 응답 지연 개선 계획 보고서 초안을 쓰려고 해.
[PE4 절차] 현황 · 문제 → 개선안 3가지 → 일정 · 기대 효과 순서로 써줘.
[PE5 샘플] 목차 : 1. 추진 배경 2. 현황 · 문제점 3. 개선 방안 4. 추진 일정 5. 기대 효과
[PE6 자료] 아래 메모만 근거로 써. 없는 수치는 [확인 필요]로 표시해.
[PE7 형식] 개조식, A4 1장 분량, 표 1개 포함.

## 예시 ③ 숏폼 기획
[PE1 역할] 너는 숏폼 조회수 100만을 여러 번 만든 기획자야.
[PE2 대상] 나는 1인 브랜드 운영자고, 보는 사람은 20대 여성이야.
[PE3 목표] 신제품을 알리는 25초 릴스를 기획하려고 해.
[PE4 절차] 기획안 3개를 한 줄씩 → 내가 고르면 신 4~5개 구성안 표로.
[PE5 샘플] 첨부한 릴스 캡처의 자막 스타일을 참고해.
[PE6 자료] 제품 정보는 아래 메모만 써.
[PE7 형식] 표 : 신 / 화면 / 나레이션 / 자막 / 길이.
