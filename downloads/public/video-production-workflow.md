## 3. 레퍼런스 준비

- [ ] 캐릭터 시트

- [ ] 주요 소품 이미지

## 4. 장면 생성

- [ ] 각 장면을 짧고 단순한 동작으로 구성했다.
- [ ] 캐릭터와 배경 레퍼런스를 동일하게 사용했다.
- [ ] 카메라 방향과 움직임을 적었다.
- [ ] 입 모양이 필요한 장면과 내레이션 장면을 구분했다.
- [ ] 장면마다 배경음악 포함 여부를 명확히 적었다.

## 5. 편집 확인

- [ ] 장면 순서가 스토리보드와 같다.
- [ ] 자막이 화면 밖으로 잘리지 않는다.
- [ ] 음성, 효과음, 배경음악의 크기가 적절하다.
- [ ] 첫 3초 안에 핵심 장면 또는 문장이 나온다.
- [ ] 마지막 화면의 행동 유도 문구를 확인했다.
