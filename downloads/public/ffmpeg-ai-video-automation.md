# FFmpeg + AI 영상 자동화 실습 가이드

캐릭터시트·로고·대본·음원을 한 폴더에 모아두고, 원하는 장면 흐름을 설명해 MP4 완성본을 만드는 실습입니다.

## 1. 두 가지 작업 방식

### 직접 설치해서 쓰기

- Python, FFmpeg, Pillow, numpy 등을 설치합니다.
- 한 번 구성한 뒤에는 실행 파일이나 배치 파일로 반복 제작할 수 있습니다.
- 설치와 오류 해결은 직접 해야 합니다.

### 연결된 작업 폴더에서 AI에게 요청하기

- 별도 명령을 외우기보다 폴더의 소스를 확인하고 조합하도록 요청합니다.
- 파일 추가·교체와 결과물 관리가 쉽습니다.
- 처음 실습하거나 휴대폰에서 결과만 확인할 때 편합니다.

## 2. 폴더에 모아둘 소스 4가지

| 소스 | 용도 | 준비 팁 |
|---|---|---|
| 캐릭터시트 | 등장 인물·포즈·표정 | 배경 제거 후 필요한 컷만 사용 |
| 로고 | 마지막 아웃트로 | 투명 배경 PNG 권장 |
| 대본 | 장면 순서·화면 문구 | 문장 순서를 확정해 저장 |
| 음원 | 배경음 | 사용 권한과 길이 확인 |

> 내레이션은 직접 녹음하거나 외부 TTS로 준비해 같은 폴더에 넣습니다.

## 3. 폴더 정리 예시

```text
video-project/
├─ character-sheet.png
├─ logo.png
├─ script.txt
├─ bgm.mp3
├─ narration.wav       # 선택
└─ output/             # 완성본 저장 위치
```

## 4. 진행은 3단계

1. **폴더 정리** — 캐릭터시트·로고·대본·음원을 넣습니다.
2. **대략 설명** — 몇 초에 무엇이 나오고 어떤 분위기인지 말합니다.
3. **완성본 확인** — MP4를 보고 필요한 구간만 다시 수정 요청합니다.

## 5. 그대로 복사하는 제작 요청문

```text
연결된 작업 폴더에 있는 소스로 릴스 영상을 만들어줘.

- 캐릭터시트, 로고, 대본, 음원 파일이 모두 폴더에 있어. 먼저 파일을 확인하고 각각 어떤 용도로 사용할지 짧게 정리해줘.
- 캐릭터시트는 배경을 제거하고 필요한 컷만 사용해줘.
- 로고는 마지막 장면인 아웃트로에 넣어줘.
- 전체 색감은 [브랜드 색상·분위기 입력] 톤으로 맞춰줘.
- 폴더에 있는 음원을 배경음으로 우선 사용해줘. 없거나 사용할 수 없으면 임의로 대체하지 말고 알려줘.
- 대본은 파일의 문장과 순서를 바꾸지 말고, 전체 길이에 맞춰 장면별 시간을 배분해줘.
- 요소가 등장할 때 간단한 모션과 효과음을 넣되, 내용 전달을 방해하지 않게 해줘.
- 화면 비율은 [9:16 또는 16:9], 전체 길이는 [초]로 해줘.
- Python과 FFmpeg로 제작하고 완성본은 같은 폴더에 MP4로 저장해줘.
- 렌더링 전에 장면별 길이·화면 요소·음향을 표로 보여주고, 빠진 소스나 결정할 항목이 있으면 먼저 질문해줘.
- 완성 후에는 사용한 소스, 출력 파일명, 해상도, 길이와 수정 가능한 항목을 알려줘.
```

## 6. 가능한 작업과 한계

### 가능한 작업

- 지정한 장면에 이미지 배치
- 캐릭터시트 배경 제거와 필요한 컷 활용
- 배경음 믹싱과 기본 음량 조절
- 요소 등장 효과와 간단한 모션·효과음 생성
- 대본 분량에 따른 장면 길이 배분

### 따로 준비하거나 다른 도구가 필요한 작업

- 목소리 생성: 직접 녹음하거나 외부 TTS 사용
- 복잡한 캐릭터 관절 움직임: 전문 애니메이션 도구 권장

## 7. 결과 확인 체크리스트

- [ ] 대본 문장과 순서가 바뀌지 않았다.
- [ ] 캐릭터 배경 제거가 자연스럽다.
- [ ] 로고가 마지막 장면에 선명하게 보인다.
- [ ] 배경음이 대사나 내레이션을 덮지 않는다.
- [ ] 효과음과 모션이 너무 과하지 않다.
- [ ] 화면 비율·해상도·전체 길이가 목적에 맞다.
- [ ] 원본을 덮어쓰지 않고 버전별로 저장했다.

## 8. 수정 요청문

```text
같은 작업 폴더의 기존 프로젝트와 완성본을 기준으로 아래 내용만 수정해서 새 버전으로 다시 만들어줘. 기존 파일은 덮어쓰지 말고 파일명 끝에 _v2를 붙여 저장해줘.

- 수정할 구간: [예: 00:04~00:07]
- 현재 문제: [예: 캐릭터가 너무 작음]
- 원하는 변경: [예: 캐릭터를 화면 높이의 약 45%로 확대]
- 유지할 요소: [예: 대본 순서, 배경음, 전체 길이]
- 추가할 요소: [없으면 없음]
- 제거할 요소: [없으면 없음]

먼저 수정 전·후 차이를 짧게 정리한 뒤 렌더링해줘. 완료 후 새 파일 경로와 달라진 항목을 알려줘.
```
