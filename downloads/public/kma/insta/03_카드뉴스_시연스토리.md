# 카드뉴스 시연 (강사) — 정보성 스토리 3개, 각 4장

## ① 빵, 이렇게 보관하면 3일 더 맛있다 → 챗GPT 이미지 방식
1 표지 / 2 실온은 하루까지 / 3 오래 두려면 냉동(1개씩 랩) / 4 데울 땐 에어프라이어 3분

## ② 인스타, 언제 올려야 할까? → 클로드 HTML 방식
1 표지 / 2 출근 전·점심 / 3 퇴근 후·자기 전 / 4 주말·연휴는 증량

## ③ 릴스 첫 3초, 멈추게 하는 3가지 (예비)
1 표지 / 2 문자 후킹 / 3 언어 후킹 / 4 시각 후킹

## 시연 순서
상담 → 4장 미리보기(스토리보드 한 장) → 컨펌 → 생성

## 챗GPT (이미지)
