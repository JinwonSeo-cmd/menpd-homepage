# KB · 도식 규칙

## 어떤 숫자에 어떤 도식
- 비율 · 구성비 → 도넛 (예: 우려 사항 보안 46 · 정확성 31 · 사용법 23)
- 항목 비교 → 가로 막대 (예: 업무별 주당 시간)
- 전후 비교 → 두 막대 + 화살표 (예: 시범 도입 전 → 후)
- 순서 · 단계 → 흐름도 (예: 1단계 → 2단계 → 3단계)

## 공통
- 도식 하나에 메시지 하나, 제목은 결론으로 ("보안 우려가 가장 큼")
- 색 : 강조 1색(주황) + 나머지 회색
- 숫자는 도식 위에 직접 표기, 범례 최소화
- 한 쪽에 도식 2개까지
