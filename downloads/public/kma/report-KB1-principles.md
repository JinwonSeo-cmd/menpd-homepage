# KB · 보고서 잘 쓰는 7원칙

1. 두괄식 — 결론과 요청 사항이 맨 위, 배경은 그 다음
2. 한 줄 한 메시지 — 한 줄에 내용 하나, 40자 이내
3. 3의 법칙 — 요약 3줄 · 전략 3개 · 기대 효과 3개
4. So What — 모든 항목 끝에 "그래서 무엇을 한다"
5. 표로 보여 주기 — 비교 · 부서별 · 일정은 반드시 표
6. 위험까지 먼저 — 예상 문제와 대응을 먼저 적어 질문을 막는다
7. 결정 요청 분명히 — 임원이 "예/아니오"로 답할 수 있게
