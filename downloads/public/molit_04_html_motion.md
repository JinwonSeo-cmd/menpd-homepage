# HTML 모션 디자인 (molit_04_html_motion.md)

> 보고서를 "태블릿에서 만져 보는 캠페인 웹페이지"로 바꾸는 규칙입니다. 고치지 말고 그대로 붙여넣으세요.

## 1. 목표
- 앞에서 쓴 보고서 내용으로 움직이는 HTML 페이지 1개를 만든다.
- 질문하지 말고 바로 만든다. 파일 하나에 모두 담는다(외부 라이브러리 없이).
- 태블릿 세로 화면 기준, 손가락으로 누르기 쉽게(버튼 최소 48px).

## 2. 분위기
- 겨울 밤 도로: 배경 딥네이비 #0F1B33 → 아래로 갈수록 #1F2A44
- 포인트: 안전 옐로 #FFC629, 얼음 하늘색 #9FD8FF
- 글꼴: Noto Sans KR(없으면 기본 고딕), 제목은 아주 크게

## 3. 반드시 넣을 모션 (전부)
1. 눈 내리는 배경: 작은 흰 점들이 천천히 계속 떨어진다
2. 옆에서 등장하는 제목: 각 섹션 제목이 화면에 들어올 때 왼쪽에서 미끄러져 들어온다
3. 타이핑 효과 본문: 맨 위 핵심 메시지가 한 글자씩 타이핑되고 커서가 깜빡인다
4. 누르면 내려오는 메뉴: 5대 수칙은 아코디언. 수칙 제목을 누르면 설명이 부드럽게 내려오고, 다시 누르면 접힌다
5. 아래에서 떠오르는 카드: 타깃·채널·기대효과 카드가 스크롤하면 하나씩 떠오른다
6. 반짝이는 슬로건: 맨 아래 추천 슬로건이 옐로로 천천히 빛났다 꺼졌다 한다
7. 얼음 반짝임: "블랙아이스" 글자에 하늘색 빛이 스치고 지나간다
8. 상단 진행 바: 스크롤한 만큼 옐로 바가 차오른다
9. 맨 위로 버튼: 오른쪽 아래 둥근 버튼, 누르면 부드럽게 맨 위로

## 4. 화면 순서
1. 첫 화면: 큰 제목 + 타이핑 핵심 메시지 + "아래로" 화살표(통통 튐)
2. 추진 배경
3. 5대 수칙(아코디언)
4. 홍보 방법 카드(타깃·채널·마스코트)
5. 일정·기대효과 카드
6. 마무리: 반짝이는 슬로건 + 부서명·이름 + "※ 교육용 가상 자료"

## 5. 금지
- 보고서에 없는 숫자·통계 추가
- 너무 빠른 깜빡임(1초에 3번 이상)
- 글자가 배경에 묻히는 색 조합
