# 섬산련 생성형 AI 실습 자료 안내

수업에서는 아래 순서로 진행합니다.

1. PPT 제작 봇 — 강사 시연, Claude 유료 기능 사용
2. 리서치 봇 — 무료 버전
3. 리서치 봇 — 유료 버전
4. 보고서·기획서 초안 봇 — 무료 버전
5. 보고서·기획서 초안 봇 — 유료 버전

Claude 무료 버전을 사용하는 분은 2번과 4번 실습만 진행해도 됩니다. 유료 버전용 자료는 수업 후 참고용으로 내려받을 수 있습니다.

## 폴더 구성

- `ppt`: PPT 봇 지침, 디자인 규칙, 스타일 라이브러리, 예시 결과물
- `research-free`: 무료 리서치 봇 지침과 예시 결과
- `research-paid`: 유료 리서치 봇 지침과 예시 결과
- `report-free`: 무료 대화창에 붙여넣는 보고서 초안 프롬프트
- `report-paid`: 유료 보고서 봇 지침, KB 묶음, 예시 초안

## 사용 전 확인

- 파일 속 지침을 Claude 프로젝트나 새 대화의 지침으로 사용합니다.
- 자료에 포함된 예시 결과는 형식 참고용입니다.
- 생성 결과의 수치·출처·법령은 반드시 원문과 대조합니다.
