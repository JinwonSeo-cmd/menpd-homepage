# 디자인 규칙 (모든 스타일 공통)

md 샘플은 **웹 디자인 시스템**이다. 색·서체 성격·모서리·분위기·금지 규칙은 **선택한 md가 우선**, 아래 규칙은 PPT용 구성·크기·검수 기준이다. 충돌하면 md의 정체성을 지키고 구도·크기·여백만 PPT에 맞게 재설계한다.

우선순위: **정확성 → 메시지 전달력 → 시각적 위계 → 정보 구조 → 미적 완성도**

## 1. 캔버스·분량
- 16:9, 최대 10장. 표지 → 본문 → 요약/결론(행동).
- 한 장 = 메시지 1개. 제목은 **메시지형 문장**("교육은 직무별 시범으로 시작합니다"). 자료에 없는 효과를 확정적으로 쓰지 않는다.
- 보고용(기관장·임원)이면 흐름: 결론 → 현황 → 문제 → 분석 → 해결 → 실행 → 결정 요청. 강의·제안·창의형은 내용에 맞게 조정.

## 2. 시각적 위계
- 정보를 3단계로: 1차(결론·핵심 숫자) / 2차(근거) / 3차(조건·기준일·출처).
- **슬라이드당 시각적 주인공 1개.** 크기·굵기·위치·여백으로 강조하고, 색 남용은 피한다.
- 모든 요소에 같은 강도를 주지 않는다.

## 3. 그리드·여백
- 12열 그리드 기준, 제목·본문·차트·페이지 번호 위치 통일, 어긋난 미세 간격 제거.
- 비대칭은 의도적일 때만. 바깥 여백 0.6in 이상.
- 관련 정보는 가깝게, 다른 주제는 멀리. 면적을 억지로 채우지 않는다. 강조 장은 넓은 여백으로 핵심 문장·숫자의 존재감을 키운다.
- 모서리·테두리·카드 형태는 md 그대로 (예: te=직각, Wise=알약형).

## 4. 글자
| 용도 | pt |
|---|---|
| 표지 제목 | 40–54 |
| 슬라이드 제목 | 28–36 |
| 소제목 | 20–24 |
| 본문 | 16–20 (최소 14) |
| 캡션·출처 | 12 이상 |
- 본문 최대 5줄/3블록. 넘치면 장을 나누거나 줄인다.
- 얇은 md 서체(weight 100/320 등)도 PPT 본문은 **최소 300**.
- 긴 문장은 의미 단위로 줄바꿈. 한글은 단어 중간에서 끊지 않는다.
- 중요한 숫자·짧은 문장은 독립 시각 요소로 다룬다.

## 5. 폰트
- **사용자가 봇지침 3단계에서 고른 폰트가 최우선.** 미선택 시 기본값:
  - 한글 Pretendard → 없으면 맑은 고딕 / 영문 md의 substitute → 없으면 Arial / 모노 Consolas
- 한 파일에 서체 최대 2종.

## 6. 색·대비
- md의 hex만 사용. **새 강조색·그림자 임의 추가 금지.** 포인트 색은 md가 허용한 만큼만.
- 대비는 색보다 구성으로: 큰 제목↔작은 본문, 굵음↔얇음, 정보 밀집↔여백, 큰 숫자↔짧은 설명.
- 본문 대비 4.5:1 이상. 어두운 md는 배경 전체를 어둡게.

## 7. 레이아웃 다양화 (구조적 다양성)
메시지 성격에 맞춰 장마다 구도를 고른다. 그리드·타이포·색은 공통 유지.
- **핵심 메시지형** 큰 문장 + 여백 / **핵심 수치형** 숫자 1개 + 비교 기준 / **비교형** 열·표 / **원인형** 연결선·흐름도 / **프로세스형** 단계 배치 / **실행계획형** 일정·담당·과제·지표 / **결론형** 권고안·근거·결정 요청
- 피할 것: 같은 카드 3개 반복, 전부 글머리표, 동일 크기 상자, 의미 없는 아이콘·장식·구분선, 모든 내용을 둥근 사각형에 넣기. (단, md 고유 요소로 의도·기능이 분명하면 md 우선)
- 차분한 분석 장과 강한 메시지 장을 섞어 리듬을 만든다.

## 8. 숫자·차트
- 핵심 수치는 단위·기준 시점·비교 대상·증감을 함께, **의미를 제목/한 줄로** ("응답자의 35%가 교육 희망"). 의미 없는 숫자 강조 금지.
- 유형: 추이=선 / 규모 비교=막대 / 비중=100% 누적·구성비 / 단계=도형 / 대안=비교표 / 인과=관계도 / 목표 대비=목표선 차트.
- 제목에 해석, 눈금선·장식 제거, md 팔레트만, 단위 표시, 축 왜곡·3D 금지, 편집 가능한 PPT 차트 객체 사용.
- 원본 데이터가 부족하면 차트를 만들지 않는다. 차트가 더 어렵게 하면 표·큰 숫자로 대체.
- 이미지는 사용자가 준 것만. 없으면 도형·큰 숫자로. 출처·기준일은 하단 캡션.

## 9. 슬라이드별 제작 절차
메시지 파악 → 위계 결정 → 표현 방식(문장/숫자/표/차트/구조도) → 레이아웃 → md 토큰 적용 → 불필요 요소 제거 → 균형 점검 → **렌더링해 글자 잘림·겹침 확인**.

## 10. 최종 검수 (제출 전, 이미지로 확인)
1. 3초 테스트: 가장 중요한 것이 바로 보이는가
2. 메시지: 한 장 = 한 주장
3. 시선: 주인공에 먼저 가는가
4. 정렬·여백: 기준선·간격 정돈, 밀도 균형
5. 리듬: 단조로운 반복 없음
6. 신뢰성: 숫자·차트가 사실 그대로, 자료에 없는 수치 없음
7. 규격: 10장 이하, 최소 글자 크기, 대비, md의 Don't 위반 없음
8. 보고용이면: 판단과 필요한 행동이 명확한가

최종 질문: "이 슬라이드는 더 많은 것을 보여주려 하는가, 더 중요한 것을 명확히 보여주려 하는가?" → 항상 후자.
