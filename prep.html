  • "이런 상황에서 이런 톤으로" 처럼 예시를 들어 요청하면 결과가 훨씬 좋아집니다.

생성형 AI 강의 준비사항

구글 플로우(Google Flow) 로그인 AI 이미지·영상 생성 실습에 사용합니다.
로그인 열기 ↗
구글 플로우 (Google Flow) — 이미지·영상을 만들어주는 구글의 생성 도구설명 보기

언제 쓰면 좋을까요?

문장으로 설명만 하면 이미지나 짧은 영상을 만들어줍니다. 카드뉴스용 이미지, 영상 소재 제작 실습에 사용합니다.

시작하는 흐름

구글 계정으로 로그인 → labs.google/flow 접속 → 새 프로젝트 만들기 → 원하는 이미지·영상 내용을 문장으로 입력 → 생성 결과 확인 후 다운로드

기본 팁

  • 스타일·구도·색감처럼 구체적인 표현을 넣을수록 원하는 결과에 가까워집니다.
  • 한 번에 여러 버전이 나오니, 마음에 드는 걸 골라 다운로드하면 됩니다.
수노(Suno) AI 로그인 AI 음악 생성 실습에 사용합니다.
로그인 열기 ↗

언제 쓰면 좋을까요?

가사와 스타일만 정해주면 실제 노래(보컬+반주)를 완성해줍니다. 강의 오프닝 음악, 홍보 영상 배경음악, 나만의 로고송 만들기 등에 활용합니다.

시작하는 흐름

구글 계정 또는 이메일로 로그인 → 새 곡 만들기 → 원하는 분위기·가사를 텍스트로 입력 → 생성된 곡 중 마음에 드는 버전 선택 → 다운로드

기본 팁

  • 장르, 분위기, 보컬 톤(예: "잔잔한 어쿠스틱", "신나는 팝")을 구체적으로 적을수록 원하는 결과에 가까워집니다.
  • 한 번에 2가지 버전이 생성되니, 둘 다 들어보고 고르면 됩니다.
일레븐랩스(ElevenLabs) 로그인 AI 음성 생성 실습에 사용합니다.

언제 쓰면 좋을까요?

글로 쓴 대본을 사람 목소리처럼 자연스러운 음성으로 변환합니다. 영상 나레이션, 오디오 콘텐츠, 다국어 더빙 등에 활용합니다.

시작하는 흐름

구글 계정 또는 이메일로 로그인 → Text to Speech 메뉴 선택 → 대본 텍스트 입력 → 원하는 목소리(보이스) 선택 → 생성 후 오디오 다운로드

기본 팁

  • 기본 제공되는 목소리 중에서 톤(차분한/발랄한 등)을 미리 들어보고 고르면 원하는 느낌을 빨리 찾을 수 있습니다.
  • 무료 이용량에 한도가 있으니, 강의 실습 전에 미리 한 번 테스트해보는 걸 추천합니다.
캡컷(CapCut) 설치 영상 편집 실습에 사용합니다. 노트북 또는 스마트폰에 미리 설치해두세요.

언제 쓰면 좋을까요?

촬영하거나 AI로 만든 영상 소스를 잘라 붙이고, 자막·음악·효과를 넣어 완성된 영상으로 만들 때 사용합니다. 초보자도 쉽게 배울 수 있는 인터페이스가 특징입니다.

시작하는 흐름

데스크톱 또는 모바일에 설치 → 구글/이메일 계정으로 로그인(선택) → 새 프로젝트 만들기 → 영상·이미지·음악 파일 불러오기 → 자르기·자막·효과 추가 → 내보내기(저장)

기본 팁

  • 계정 로그인 없이도 바로 편집을 시작할 수 있지만, 로그인하면 작업 내용이 클라우드에 저장돼 기기 간 이어서 작업하기 편합니다.
  • 자막은 자동 생성 기능을 먼저 써보고, 어색한 부분만 손으로 수정하면 시간이 절약됩니다.

핀터레스트 이미지 검색과 무드보드로 디자인 영감을 모으는 사이트입니다.

핀터레스트 (Pinterest) — 이미지와 무드보드로 디자인 영감을 모으는 사이트설명 보기

언제 쓰면 좋을까요?

카드뉴스·포스터·슬라이드를 만들기 전, 참고할 만한 이미지나 배치 아이디어를 모을 때 사용합니다.

시작하는 흐름

구글 계정으로 로그인(선택) → 검색창에 원하는 키워드 입력 → 마음에 드는 이미지를 보드에 저장 → 저장한 보드를 참고자료로 활용

기본 팁

  • 로그인하지 않아도 검색과 열람은 가능하지만, 로그인하면 이미지를 보드로 저장해 모아볼 수 있습니다.
  • 키워드를 영어로 검색하면 훨씬 다양한 레퍼런스가 나옵니다.
언스플래시 저작권 걱정 없이 쓸 수 있는 무료 고화질 사진 사이트입니다.
바로가기 ↗

기본 팁

  • 로그인 없이도 대부분의 사진을 무료로 다운로드할 수 있습니다.
  • 출처 표기가 필수는 아니지만, 작가명을 함께 적어주면 더 좋습니다.

바로가기 ↗
Refero Styles — 실제 서비스의 디자인 시스템 레퍼런스설명 보기

언제 쓰면 좋을까요?

실제 서비스들이 어떤 색상·폰트·여백·버튼 스타일을 쓰는지 참고해 디자인 톤을 정할 때 유용합니다.

시작하는 흐름

styles.refero.design 접속 → 마음에 드는 서비스·브랜드 카드 선택 → 색상 팔레트·폰트·컴포넌트 스타일 확인 → 우리 자료에 맞게 응용

기본 팁

  • 완성된 디자인을 그대로 베끼기보다, 색상 조합이나 여백 감각처럼 '원리'를 참고하는 용도로 쓰는 게 좋습니다.
  • 마음에 드는 스타일 몇 개를 골라 캡처해두면 나중에 비교하기 편합니다.

계정이 없으신 항목은 강의 전 미리 가입해두시면 실습 시간을 아낄 수 있습니다. 로그인에 어려움이 있으시면 강의 당일 조금 일찍 접속해 도움을 요청해주세요.
