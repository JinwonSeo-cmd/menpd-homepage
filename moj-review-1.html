01지난 시간 복습

생성형 AI는 4종류가 있습니다
  • 글 : 챗GPT, 제미나이
  • 이미지 : 챗GPT, 구글 플로우
  • 소리 (음악·음성) : 수노, 일레븐랩스
  • 영상 : 구글 플로우, 캡컷 시댄스
프롬프팅 기법
  • PE7로 쓰면 결과가 좋아집니다.
샘플 넣고 포스터 디자인
  • 샘플을 넣으니 결과가 달라졌습니다.
MD · INS · KB 개념
  • MD : 글을 담는 파일 형식
  • INS(지침) : 봇에게 “어떻게 하라”고 적어 둔 것
  • KB(지식) : 봇에게 “무엇을 보고 하라”고 주는 자료
챗GPT에서는 조금 다릅니다
  • 프로젝트의 지침 칸이 INS입니다.
  • 프로젝트의 파일 칸이 KB입니다.
  • 컴앱웹에서는 내 폴더의 MD 파일이 KB 역할을 합니다.
프롬프팅 → MD → 봇 (다음 시간에 제대로)
컴앱웹 개념
  • 컴 : 내 컴퓨터의 폴더·파일
  • 앱 : 챗GPT 데스크톱 앱
  • 웹 : 챗GPT 안의 내부 웹
  • 이 셋이 데스크톱 앱 하나로 이어지면 컴앱웹이 완성됩니다.

03미리 세팅해 보세요 권장!

컴앱웹 세팅입니다.

앱 : 챗GPT 데스크톱 앱 설치 + 로그인설치 후 같은 계정으로 로그인합니다.
다운로드 ↗
📁
컴 : 수업용 폴더 만들기바탕화면에 법무부AI 폴더를 만들어 주세요.
🌐
웹 : 챗GPT 앱에서 내부 웹 켜기데스크톱 앱 안에서 내부 웹이 켜져야 합니다. 이 김에 구글 로그인도 해 둡니다. PC에서 해 주세요.
1

챗GPT 데스크톱 앱을 엽니다.바탕화면이나 시작 메뉴의 챗GPT 아이콘을 눌러요.

2

로그인이 되어 있는지 확인합니다.안 되어 있으면 로그인해 주세요.

3

아래 복사 버튼을 누릅니다.“복사 완료 ✔︎”가 뜨면 성공입니다.

📋 내부 웹 테스트 문장
내부웹으로 구글 플로우에서 '구름 위 하늘을 나는 귀여운 시바견(법무부 로고가 있는 스카프를 단) 가로 이미지 생성하고 5초짜리 영상으로 생성해줘.'
4

챗GPT 앱 맨 아래 글 쓰는 칸을 한 번 클릭합니다.

5

키보드에서 Ctrl 을 누른 채 V 를 눌러 붙여넣습니다.

6

Enter 를 눌러 보냅니다.

7

잠시 기다리면 작은 창(내부 웹)이 열리고 구글 플로우가 나옵니다.이때는 마우스를 건드리지 말고 지켜봐 주세요.

8

구글 로그인 창이 나오면 내 이메일과 비밀번호를 직접 입력합니다.다음 수업부터 내부웹 로그인을 많이 써서 꼭 필요한 로그인입니다.

9

영상이 만들어지면 끝입니다. 한 번만 해 보세요.

10

안 되면 화면을 캡처해서 단톡방에 올려 주세요.

04만져보며 로그인하기 추천

수노 일레븐랩스 구글 플로우 캡컷 웹
캡컷 웹은 시댄스 2.0 미니만 써 보세요
  • 이것도 챗GPT 앱의 내부웹으로 해 봅니다.
  • 아래 문장을 복사해서 챗GPT 앱에 붙여넣고 보내세요. (위 웹 단계와 같은 방법입니다.)
  • 캡컷 로그인 창이 나오면 직접 로그인해 주세요.
  • 메뉴가 안 보이면 건너뛰어도 됩니다.
📋 캡컷 웹 테스트 문장
내부웹으로 캡컷 웹에서 시댄스 2.0 미니로 '구름 위 하늘을 나는 귀여운 골든리트리버(법무부 로고가 있는 스카프를 단)' 5초짜리 영상으로 생성해줘.
🚨 다른 모델은 비싸서 크레딧이 금방 없어집니다.
시댄스 2.0 미니 외에는 하지 마세요.
영상은 딱 한 편만 만들어 보세요.
