02

다시 점검 ② 폴더

폴더 연결이 안 됐던 분들은 대부분 원드라이브 때문이었습니다.

❌ 이렇게 하지 마세요

  • 컴퓨터 전체·문서 폴더를 원드라이브에 걸어 둔 채 연결
  • 원드라이브 안 폴더를 챗지피티에 연결
  • 여러 폴더를 여기저기 연결

✅ 이렇게 하세요

  • 바탕화면에 독립 폴더 1개 (예: AI작업)
  • 그 폴더 하나만 챗지피티 앱에 연결
  • 결과물도 모두 그 폴더 안에

따라하기 3단계

  1. 바탕화면 빈 곳 우클릭 → 새로 만들기 → 폴더 → 이름 AI작업
  2. 폴더 우클릭 → 속성에서 위치 확인주소에 OneDrive가 들어 있으면 ❌ → 원드라이브 밖에 다시 만드세요 (예: C:\Users\내이름\Desktop)
  3. 챗지피티 데스크톱 앱에서 이 폴더만 연결 → 아래 문장으로 확인“이 폴더에 test.txt 만들어줘” → 폴더에 파일이 생기면 성공
폴더 안 구성은 1주차와 같습니다 — 소스 · 샘플 · MD · 결과. ‘AI작업’ 템플릿 zip 받기

04

봇의 뼈대 — INS와 KB

폴더에 MD 파일을 넣어 두면 챗지피티가 그걸 읽고 일합니다.

파일역할예시
INS (agent MD)봇이 어떤 순서로 일할지주제 묻기 → 구성안 3안 → 컨펌 → 생성 → 결과 폴더 저장
KB · 규칙어떤 기준으로 만들지디자인 규칙.md, 보고서 작성 규칙.md
KB · 대가의 뇌누구처럼 생각할지리서치 대가, 숏폼 기획 대가
AI작업/ ├─ MD/ │ ├─ INS_숏폼봇.md ← 일하는 순서 │ ├─ KB_디자인규칙.md ← 기준 │ └─ KB_기획대가.md ← 대가의 뇌 ├─ 샘플/ ├─ 소스/ └─ 결과/
INS는 순서, KB는 기준. 둘 다 있으면 매번 같은 품질이 나옵니다. MD·KB 파일은 준비사항 1주차에서 받을 수 있습니다.

06

HTML로 PPT 만들기

요즘은 HTML로 먼저 만들고, 필요할 때 PDF·PPT로 받는 방식이 대세입니다. 챗지피티만으로 따라 할 수 있습니다.

PPT보다 HTML인 이유 10가지

1말 한마디면 수십 장도 통째로 만듭니다
2수정도 말로. 사진 10장 정렬도 순식간
3모션이 쉽습니다. “키워드가 눈처럼 쏟아지게” 한마디
4PPT 파일로 만들 때보다 대체로 토큰이 덜 듭니다
5공유는 링크 하나. 파일을 보낼 필요 없음
6폰이든 PC든 화면에 맞춰 자동으로 바뀜
7프로그램 없이 브라우저만 있으면 열림
8디자인 MD가 그대로 먹힙니다. 매번 같은 톤
9복사 버튼·클릭·퀴즈까지. 보는 자료가 아니라 쓰는 자료
10필요하면 PDF·PPT로 변환. 원본은 HTML로

카드가 하나씩 올라오는 것도 HTML 모션입니다. 이 페이지 자체가 예시예요.

재료 준비

재료형태넣을 폴더

생성 — 목차 먼저, 컨펌 후 생성

📋 HTML 발표자료 생성
AI작업/소스의 원고로 HTML 발표자료를 만들어줘.
- 16:9 (1280×720), ___장
- 키보드 방향키로 넘기기, 하단에 쪽 번호
- 파일 1개(HTML 안에 CSS·JS 포함)
- 디자인은 MD 폴더의 디자인 MD 규칙을 따를 것
- 글이 많은 장은 표·흐름도·비교 카드로 바꿔줘
- 먼저 장별 목차만 보여주고, 내가 OK하면 만들어
- 완성 파일은 AI작업/결과/발표.html 로 저장
한 번에 끝까지 만들지 마세요. 목차 → OK → 생성 순서로 가면 수정이 줄고 토큰도 아낍니다.

HTML로 움직이는 카드뉴스

이미지 카드뉴스는 멈춰 있지만, HTML 카드뉴스는 글자·숫자·도형이 움직여 영상처럼 보입니다. 화면 녹화하면 바로 릴스가 됩니다.

흐름도형크게
비교형크게

규격

📋 움직이는 카드뉴스 생성
주제: ___
이 주제로 움직이는 카드뉴스를 HTML 파일 1개로 만들어줘.
- 4:5 (1080×1350), 4장, 장당 3.5초 자동 넘김, 마지막 장 후 처음으로 반복
- 1장: 후킹 제목 / 2~3장: 핵심 내용 / 4장: 정리 한 줄
- 모션: 제목 아래에서 등장, 숫자 카운트업, 흐름도 선 그리기
- 글은 장마다 2줄 이내, 크게
- 디자인은 MD 폴더의 디자인 MD 규칙을 따를 것
- 먼저 장별 문구만 보여주고, 내가 OK하면 만들어
- 완성 파일은 AI작업/결과/카드뉴스.html 로 저장

유형별로 한 줄 추가

기본 프롬프트 아래에 붙여넣으세요. 위 샘플 3종이 이렇게 만들어졌습니다.

📋 + 숫자 강조형
각 장 핵심 숫자를 화면 절반 크기로, 0부터 카운트업.
이전 숫자는 회색 취소선, 새 숫자는 강조색으로.
📋 + 흐름도형
2~3장은 3단계 흐름도로. 상자가 순서대로 나타나고 화살표가 그려지게.
📋 + 비교형
전/후를 좌우로 나눠줘. 왼쪽은 회색으로 흐려지고, 오른쪽은 강조색으로 밀려 들어오게.

막힐 때

폴더 연결이 안 돼요
원드라이브 안 폴더인지 확인하세요. 바탕화면에 독립 폴더를 새로 만들어 그것만 연결합니다. (02 참고)
앱은 로그인됐는데 웹 작업이 멈춰요
내부 웹 로그인은 따로입니다. 앱 안 웹 화면에서 해당 사이트에 로그인하세요.
HTML 파일이 글자로만 보여요
메모장으로 열린 것입니다. 파일 우클릭 → 연결 프로그램 → 크롬 또는 엣지.
모션이 안 움직여요
캔버스 미리보기 대신 파일로 저장해 더블클릭으로 여세요.
PDF 배경이 하얗게 나와요
인쇄 설정 → 더 많은 설정 → 배경 그래픽 체크.
일레븐랩스 한국어 목소리가 안 보여요
보이스 라이브러리에서 언어 필터를 Korean으로 바꾸세요.
그래도 안 돼요
화면을 캡처해서 단톡방에 질문해 주세요.
