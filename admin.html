자료실 관리자

여기서 저장하면 GitHub에 바로 반영되고, 1~2분 뒤 홈페이지에 나타납니다.

연결 설정

GitHub → Settings → Developer settings → Fine-grained tokens에서 발급하세요. 저장소는 이 홈페이지 하나만, 권한은 Contents: Read and write만 주면 됩니다. 토큰은 이 브라우저에만 저장되고 어디로도 전송되지 않습니다.
