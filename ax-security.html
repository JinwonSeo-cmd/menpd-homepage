동적교재 · AX 입문

AI를 도구에서
시스템으로

단순 도구 사용을 넘어, 업무 프로세스에 AI를 결합하는 AX(AI Transformation)의 개념과 API·MCP 연동 시 반드시 짚어야 할 보안 체크리스트입니다.

01 — 개념

AX는 어디쯤 있는가

TOOL 사용

개인이 도구를 쓴다

ChatGPT, Claude 같은 도구를 개인이 열어서 질문하고 답을 받는 단계. 업무는 그대로, 보조 수단만 추가됨.

AX

업무에 AI가 들어간다

반복되는 특정 업무(응대, 분류, 초안 작성 등)에 봇이나 자동화 워크플로우를 붙여, 사람은 예외 처리와 검수만 맡는 단계.

SI

시스템을 새로 짠다

전사 IT 인프라·시스템을 처음부터 설계하고 구축. 조직 규모의 개발 프로젝트로, 이 교재가 다루는 범위 밖.

02 — 연결 방식

API와 MCP, 뭐가 다른가

API는 두 프로그램이 정해진 규칙으로 데이터를 주고받는 통로이고, MCP는 AI 모델이 그 통로들에 접근할 수 있도록 표준화한 연결 방식입니다 — 흔히 "AI를 위한 USB-C"에 비유됩니다.

03 — 위험도 감

연동 전, 위험도부터 가늠하기

낮음개인이 쓰는 생산성 도구, 외부로 데이터가 나가지 않는 구조 (예: 로컬 메모 정리 봇)
중간사내 데이터를 다루지만 개인정보·기밀은 최소화된 경우 — 접근 권한 설계가 필요
높음고객정보·기밀정보를 다루거나 외부 API로 데이터가 나가는 자동화 — 반드시 보안 담당자 검토 후 진행
