FFmpeg 설치 방법

FFmpeg는 화면 없이 돌아가는 무료 영상 편집 엔진입니다. 설치만 해두면 클로드가 컷 편집·자막·음악 삽입 명령을 대신 짜서 실행합니다.

💸 무료오픈소스라 결제·구독 없음
🔓 가입 X로그인·회원가입 필요 없음
⌨️ 한 줄명령어 한 줄 복사·붙여넣기
01

🪟 윈도우 10 / 11

아래 순서대로 따라 하세요. 명령어는 복사 버튼을 누른 뒤 붙여넣기만 하면 됩니다.

1

터미널 열기

⊞ Win 키 → "터미널" 입력 → 엔터. (없으면 "PowerShell"로 검색)

2

설치 명령어 붙여넣기

터미널 창에서 Ctrl+V 또는 마우스 우클릭으로 붙여넣고 엔터. 중간에 Y를 물어보면 Y 입력 후 엔터.

winget install Gyan.FFmpeg
3

터미널 껐다가 다시 켜기

설치 직후 창에서는 바로 인식이 안 될 수 있어요. 꼭 닫고 새로 여세요.

01

🍎 맥

맥은 '홈브루'라는 설치 도우미를 먼저 깐 뒤 FFmpeg를 설치합니다. 홈브루가 이미 있다면 2번부터 하세요.

1

터미널 열기 + 홈브루 설치

⌘ Cmd+Space → "터미널" 입력 → 엔터. 아래 명령어를 붙여넣고 엔터. 맥 로그인 비밀번호를 물으면 입력(화면에 안 보여도 정상)하고 엔터.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

설치 끝에 "Next steps" 아래 명령어 2줄이 나오면, 그것도 복사해서 그대로 실행하세요.

2

FFmpeg 설치

같은 터미널에 붙여넣고 엔터. 몇 분 걸릴 수 있으니 기다려 주세요.

brew install ffmpeg
02

✅ 설치 확인

새 터미널을 열고 아래 명령어를 입력하세요.

✓

버전 정보가 나오면 성공!

ffmpeg -version
ffmpeg version 7.x ... ← 이런 글자가 나오면 완료
03

⚠️ 막힐 때

'winget'을 찾을 수 없다고 나와요
Microsoft Store에서 "앱 설치 관리자"를 검색해 업데이트한 뒤, 터미널을 다시 열고 2번을 반복하세요.
'ffmpeg'은(는) 인식되지 않는 명령이라고 나와요
터미널을 완전히 닫고 새로 여세요. 그래도 안 되면 PC를 한 번 재시작하면 대부분 해결됩니다.
'brew: command not found'가 나와요
홈브루 설치 끝에 나온 "Next steps" 명령어 2줄을 실행하지 않은 경우입니다. 1번을 다시 실행하고 마지막에 나오는 안내 명령어를 꼭 실행하세요.
회사 PC라 설치가 막혀요 (권한 오류)
관리자 권한이 필요한 경우입니다. 전산팀에 "FFmpeg 설치 요청"을 하시거나, 개인 노트북을 사용해 주세요.
그래도 안 되면?
당일 강의 시작 전에 강사에게 말씀해 주세요. 클로드 데스크톱앱에 "FFmpeg 설치해줘"라고 요청해 함께 해결할 수도 있습니다.
