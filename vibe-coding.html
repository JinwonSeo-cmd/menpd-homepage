동적교재 · 바이브 코딩

코드를 짜지 않고
대화로 만든다

바이브 코딩(Vibe Coding)은 원하는 것을 말로 설명하면 AI가 코드를 작성하고, 나는 결과를 보며 방향을 다듬는 방식입니다. 첫 프로젝트를 시작하기 위한 개념과 실습 흐름을 정리했습니다.

01 — 개념

기존 코딩과 뭐가 다른가

기존 방식

문법을 배우고, 직접 짠다

언어 문법과 라이브러리 사용법을 익힌 뒤, 한 줄 한 줄 코드를 직접 작성. 막히면 검색하고 디버깅.

바이브 코딩

의도를 말하고, 검토한다

"이런 화면, 이런 동작"을 자연어로 설명하면 AI가 코드를 작성. 나는 결과물을 써보고 고칠 부분을 다시 말로 전달.

02 — 흐름

3단계로 반복한다

01

아이디어를 구체화한다

"누가, 무엇을 위해 쓰는지"를 한두 문장으로 정리. 완성됐을 때 어떤 화면·동작인지 먼저 그려본다.

02

작은 단위로 요청한다

한 번에 전부 요청하지 않고, 기능 하나씩 순서대로 요청한다.

예: "할일을 입력하면 목록에 추가되는 화면부터 만들어줘. 삭제 기능은 다음에."
03

실행하고, 그대로 되묻는다

실행해보고 안 되거나 어색한 부분은 화면을 설명하거나 에러 메시지를 그대로 붙여넣어 되묻는다. 추측해서 고치려 하지 않는다.

03 — 실습

첫 프로젝트, 뭐부터 만들까

나만의 소개 페이지

입문

이름, 하는 일, 연락처가 담긴 한 페이지짜리 웹사이트. 완성 기준이 명확해서 첫 프로젝트로 적합.

"제 소개 페이지를 만들어줘. 이름은 OOO, 하는 일은 △△△, 연락처는 이메일 하나만."

체크리스트 / 할일 앱

초중급

입력, 완료 표시, 삭제까지 세 가지 동작이 들어가 "기능 단위로 나눠 요청하기"를 연습하기 좋음.

"할일을 입력하면 목록에 쌓이고, 클릭하면 완료 표시되는 화면부터."

데이터 정리 자동화

중급

엑셀·CSV 파일을 읽어 원하는 형태로 정리해주는 스크립트. 반복 업무 하나를 골라 그대로 적용해볼 것.

"이 CSV에서 A열 기준으로 중복을 지우고, 날짜순으로 정렬한 새 파일을 만들어줘."
