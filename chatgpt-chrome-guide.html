위에서부터 하나씩 하면 됩니다.

  • ① 설치위 [설치 페이지 열기] → Chrome에 추가 → 확장 프로그램 추가

일레븐랩스 — 나레이션한 문장을 목소리로 만들어 mp3로 받습니다.
@Chrome 일레븐랩스를 열고, 한국어 남성 목소리로 "마을변호사 무료 법률상담, 이번 주 목요일입니다."를 생성해서 mp3로 받아줘.
수노 — 주제곡키워드 5개로 노래를 만들고 링크를 받아 옵니다.
@Chrome 수노를 열고 심플 모드에 "주제 : 마을변호사 무료 법률상담 / 장르 : K-pop 징글 / 보컬 : 여성 / 빠르기 : 빠르게 / 분위기 : 밝고 따뜻하게"를 넣어 생성하고, 곡 공유 링크를 알려줘.
제미나이 — 배경음악가사 없는 BGM을 만듭니다.
@Chrome 제미나이를 열고 음악 만들기로 "공공기관 홍보 숏폼 배경음악, 가사 없이, 밝고 따뜻하게, 보통 빠르기, 피아노와 가벼운 현악, 30초"를 생성해줘.
GOOD TO KNOW

알아 둘 것

  • 화면은 안 움직여요ChatGPT가 뒤에서 일하고 결과만 보여 줍니다. 내 작업을 방해하지 않습니다.
  • 내 로그인 그대로크롬에 로그인해 둔 계정을 씁니다. 시작 전 계정이 맞는지 확인하세요.
  • 비밀번호는 채팅에 쓰지 않기로그인은 크롬 화면에서 직접 합니다.
  • 결제 · 제출은 직접돈이 오가거나 되돌리기 어려운 일은 내가 확인하고 누릅니다.

로그인이 필요 없는 공개 페이지나 앱 안에서만 할 작업은, 데스크톱 앱의 내장 브라우저(@Browser)로도 됩니다. 내 계정이 필요한 사이트는 크롬 확장이 편합니다.
